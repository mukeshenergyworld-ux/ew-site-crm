Where to paste

  1. Gmail: Settings ⚙ → See all settings → General → Signature → Create new → paste → set "For new emails" and "On reply" → Save changes.
  2. Zoho Mail: Settings → Signature → Add → paste → assign to the address → Save.
  3. Outlook.com / Outlook: Settings → Mail → Compose and reply → Email signature → paste → set defaults → Save.
  4. Yahoo Mail: Settings → More settings → Writing email → Signature → turn on for the account → paste.
  5. iCloud Mail (web): Settings ⚙ → Composing → Add a signature → paste. (iCloud web keeps plain text only.)
  6. Apple Mail (Mac): Mail → Settings → Signatures → choose account → + → paste → untick "Always match my default message font".
